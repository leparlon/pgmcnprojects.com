Vertigo Loop Privacy Policy

Effective date: September 5, 2026

Privacy Policy Terms of Use

Overview

Vertigo Loop ("the tool", "we", "our") is a private content-automation tool operated by PGMCN Projects. It uses YouTube API Services to upload and manage videos on the operator's own Vertigo Loop YouTube channel. Vertigo Loop is not a public service and does not offer registration to third-party users.

Use of YouTube API Services

Vertigo Loop uses YouTube API Services. By using Vertigo Loop, the operator acknowledges and agrees to be bound by the Google API Services User Data Policy, including the Limited Use requirements.

The current integration requests the OAuth scope https://www.googleapis.com/auth/youtube.upload to upload and manage videos on the operator's channel. No other YouTube or Google scopes are currently requested.

The YouTube Analytics API may be enabled in the associated Google Cloud project for future use, but it is not currently used by Vertigo Loop. No analytics scope is requested and no analytics data is currently accessed. This Privacy Policy will be updated before any such access is introduced.

Data We Handle

Operating Vertigo Loop involves the following categories of data:

  • OAuth access and refresh tokens issued by Google for the authorized channel.
  • Video files and upload metadata supplied or generated by the operator, such as titles, descriptions, visibility settings, and scheduling information.
  • Technical logs needed to operate and troubleshoot the automation, where applicable.

Vertigo Loop never requests, collects, or stores Google account passwords.

Where Data Is Stored

OAuth tokens and related authorized data are stored privately on systems controlled by the operator. They are not stored in, or accessible through, this GitHub Pages site, which is a static informational website only.

How Data Is Used

Google and YouTube user data accessed by Vertigo Loop is used solely to provide the explicitly authorized upload and video-management functionality on the operator's own channel. Data is not sold, and it is not shared with advertisers or unrelated third parties.

Cookies and Analytics

The Vertigo Loop pages on this site (pgmcnprojects.com/vertigo-loop/) do not use cookies, analytics, tracking scripts, forms, or third-party embeds.

Data Retention

Tokens and related authorized data are retained only for as long as needed to operate the integration.

Data Deletion

Revoking Vertigo Loop's access stops all future API access. Locally stored tokens and associated authorized data will be deleted as soon as reasonably possible, and in any case within the periods required by YouTube API Services policies.

Access can be revoked at any time through Google's account permissions page: security.google.com/settings/security/permissions.

Google's Privacy Policy

Use of Google APIs is also governed by Google's Privacy Policy.

Changes to This Policy

This Privacy Policy may be updated from time to time, including before any new scope or data use is introduced. Changes will be reflected on this page with an updated effective date.
